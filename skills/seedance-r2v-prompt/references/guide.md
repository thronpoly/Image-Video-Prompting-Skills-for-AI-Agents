# Seedance reference-to-video manual
Read prompt-writing.md and image-references.md for any R2V request. Read audio.md for voice/music/sound, editing.md for source edits or continuation, parameters.md for concrete model/provider controls, examples.md and troubleshooting.md for task patterns.

Scope: BytePlus ModelArk Dreamina Seedance 2.0 omni reference and Seedance 2.5, with explicit provider/Comfy Router distinctions. Preserve the user's version and selected service; a Seedance model hosted by another vendor can expose different fields and reference syntax. For a version-unspecified draft, state a modest 2.0 or existing-context assumption rather than silently mixing both versions.

A reference-generation task borrows selected information to generate new footage. A source-video edit changes that footage. A continuation extends it. These different intents affect both language and valid 2.5 parameters. The final prompt is an operational video specification, not MiniMax's six-section IR. Sources and dated route schemas are stored locally.
