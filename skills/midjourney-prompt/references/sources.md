## Specific source conflicts

- Current Version article says V8.2 is default; Legacy Features retains an obsolete V7-default sentence. versions.md takes precedence for current selection.
- Some feature articles retain V7-specific values or older-engine Editor behavior. Preserve the version condition; do not apply a V7 reference/quality setting to V8.
- Image Prompt weight tables explicitly name V8.1, V7 and Niji 7, not every V8 revision. Do not fabricate an unlisted V8.2 range.

The local compatibility.json records the official Version table with its yes/no symbols parsed into values. It is a dated fact snapshot, not a replacement for the detailed control chapters.
