Checked: 2026-11-03. Scope: every article in the official Documentation category except Using Discord and Midjourney Policies. Account/billing articles belong to a different category and are outside this manual. See the article-by-article coverage table in sources.md.

| User intent | Read |
|---|---|

| A particular look, product/person likeness, multiple input images | image-references.md |

| Ready-made task patterns | examples.md |
| A result misses the brief | troubleshooting.md |

Choose the model before composing flags: the current documented default is V8.2, but respect a user-selected V7/V6/Niji version. V8 reference editing and V7 Omni Reference are different routes. No-reference generation is a finished-scene description; an Edit Model request may be an imperative change instruction. Web attachments are authoritative: do not invent URLs or prepend a Discord command. Parameters remain useful in the web Imagine bar even though Discord operation is excluded.
