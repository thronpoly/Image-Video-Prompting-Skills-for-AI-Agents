# Krea diagnosis
| Problem | Check | Correction |
|---|---|---|
| Instructions have no apparent effect | Wrong Krea/base route | Identify checkpoint/provider before changing prose |
| Hosted resolution rejected | Native 2K capability copied into a 1K endpoint | Use that endpoint's actual enum or disclose limitation |
| Reference geometry drifts | Style reference mistaken for identity input | Use a supported edit/identity route; preserve design cues |
| Too much invented detail | Expansion disregards fixed inventory | Remove unrequested objects and preserve original medium |
| Generic result | No composition/material/light decisions | Add only the missing visual decisions |
| Local Turbo breaks at CFG change | RAW/Turbo or CLI/UI convention mixed | Restore selected template's documented no-CFG profile |
| LoRA trigger does nothing | Wrong base family or unsupported text-loader syntax | Verify adaptation metadata and actual node loading |
| Edit redraws whole scene | Local preservation scope unclear | Name target and base canvas, use supported regional behavior |
| No mask control exists | Platform feature assumed native | Explain selected template's limitation instead of adding nodes |
| Thinking mode rejected | Krea 3 prerequisites not met | Match model/resolution; do not copy mode into Krea 2 |

Keep prompt interpretation, image roles, hosted creativity, native guidance and learned-style strength separate. One universal “strength” slider cannot stand in for all five.
