# H3 diagnosis
| Failure | Inspect | Revision |
|---|---|---|
| Identity changes during motion | Input mapping, reference visibility, contradictory retention | Define one stable Subject, retain decisive cues, remove incompatible transformation claims |
| Character becomes immobile | Prompt emphasizes exact copying of a frame | Separate identity reference from first-frame constraint; describe joint/step changes |
| Camera moves despite locked request | Tracking/zoom language or source-camera borrowing | Borrow actor motion only; remove camera movement throughout all fields |
| Ref video gets copied as a scene | Source was not assigned a limited role | State which action/structure transfers and which setting/performer does not |
| Wrong person speaks | Subject and speaker numbering conflated | Assign S IDs by target vocal order and bind actual speech explicitly |
| Original dialogue leaks into new line | Audio timbre reference described as signal copy | Use audio reference, supply exact target dialogue and exclude transcription claims |
| Music appears in a silent clip | Score/soundscape inconsistent | Distinguish no score from complete silence and configure the actual audio route |
| Wrong playback length | Frame grid, export fps or duration mismatch | Compute effective frame count/fps; use exposed in-workflow controls |
| Ref detail is weak | Too little source detail, unconnected visual latent, small reference sizing | Inspect actual inputs before expanding prose or increasing resolution |
| Loop closes pose but still jerks | Velocity/light/background discontinuity | Design a periodic action with stable camera; inspect seam after generation |
| Request exceeds capability | Unsupported reference type, step profile or hardware load | Explain the exact mismatch; preserve official template boundaries |

Revise one cause at a time. Record identity, action readability, camera stability, reference-role correctness, speech fidelity and actual output duration as separate acceptance criteria. No executed-output claims should be inferred from a well-formed six-section text alone.
