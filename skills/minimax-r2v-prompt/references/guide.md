# MiniMax H3 full-reference manual
Read prompt-writing.md and format.md for every R2V prompt. Read image-references.md for any supplied assets; audio.md for sound, voices or reference video soundtracks; parameters.md for timing/resolution/inference requests. Use examples.md and troubleshooting.md for concrete construction and diagnosis.

This skill targets the open MiniMax H3 Ref2VA route and its Context-IR-style six-section prompt. A hosted Hailuo/H3 API, FL2VA/I2VA checkpoint and a community accelerated Ref2VA LoRA are different execution profiles. Keep a selected profile explicit. A user asking for R2V has not asked to convert their reference into a first-frame constraint. The six sections are model-facing conditioning, not an explanation to the user.

The manual contains a full writing procedure, reference role decisions, formal section/label rules, audio behavior, dated input/inference constraints and original examples. Sources and route caveats are in sources.md. Template-compatible execution settings remain separate from the English prompt body.
