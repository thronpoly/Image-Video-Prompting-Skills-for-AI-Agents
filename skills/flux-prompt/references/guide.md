# FLUX image manual
Read prompt-writing.md for any image, image-references.md for actual reference inputs, editing.md for changes/composites, parameters.md for checkpoint/provider settings, layout.md for explicit FLUX 3 boxes, examples.md and troubleshooting.md for practical decisions.

This manual distinguishes FLUX.1 generation (including Krea-adapted variants), FLUX.1 Kontext editing, FLUX.2/Klein and FLUX 3 Image. Preserve a named checkpoint and template; the latest hosted FLUX 3 controls are not a native FLUX.1 API. FLUX video/action products are outside this image skill's scope.

Use prose for finished-image generation, directives for editing and a separately validated layout form only when the selected route supports it. The manual is stored locally; source links and version-specific provenance are in sources.md. An existing reference schema or unknown slot should be checked locally at execution time rather than filled from another model's documentation.
