# FLUX diagnosis
| Failure | Inspect | Targeted fix |
|---|---|---|
| A negative list is ignored | Endpoint has no negative field | Describe the positive target state |
| Two identities blend | Inputs and ownership are vague | Assign one role per source and bind subjects/actions |
| Inserted product floats | Missing contact/scale/light relationship | Name surface, orientation and matching contact shadow |
| Canvas shape follows wrong input | Base image order or auto aspect | Put actual base first or select a supported explicit frame |
| Bounding boxes misplaced | x/y order or wrong normalization | Use [top,left,bottom,right] on the actual aspect |
| Rows reference wrong image | One-based prose versus zero-based row index | Reconcile image 1 with ref_image_0 |
| Exact text changes | Literal string or type scope missing | Quote text and target its block for editing |
| Native sampler breaks | Hosted/newer-family settings copied to old checkpoint | Restore selected template's profile |
| Reference count rejected | Playground limit copied to API/local route | Use actual exposed slots and explain shortage |
| Edited result redraws too much | Finished-scene caption used as local directive | State the change and scoped preservation |
| Precise color appears different | Material/light/tone influence | Specify target surface and lighting; inspect output color |

Check the input-to-role map before adding detail. A strong prompt does not create missing native multi-reference, mask or layout support.
