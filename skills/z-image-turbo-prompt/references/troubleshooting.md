# Z-Image diagnosis
| Result | Inspect | Revise |
|---|---|---|
| Generic output | Low-value quality tags replaced visual decisions | Define silhouette/material/composition explicitly |
| Wrong object count | Count missing or crowded action | Enumerate subjects and simplify overlaps |
| Text absent/misspelled | Exact string or placement not clear | Quote the literal string and isolate its region |
| Styles conflict | Several incompatible medium instructions | Choose the user-requested medium and consistent surface treatment |
| Reference identity not retained | T2I reconstruction mistaken for image conditioning | State the limitation; use only an authorized supported route |
| Negative prompt does nothing | Turbo no-CFG branch | Express intended scene in the positive prompt |
| Raising steps changes little | Distilled few-step profile | Keep supported schedule; repair actual content ambiguity |
| Changing guidance breaks output | Pipeline and ComfyUI conventions mixed | Restore official template's no-CFG profile |
| Large image loses composition | Aspect/prompt mismatch or resource constraints | Recompose for the selected canvas and validate actual capacity |
| Weight syntax appears literally/has no effect | Unsupported parser assumption | Use clear natural language unless the actual node documents weights |

Evaluate separately: subject identity/class, count, layout, material, palette, light, exact text and resolution. A useful revision names the failed criterion and changes a clause or one real control, rather than escalating every parameter at once.
