# Writing for Z-Image-Turbo

## Brief-to-prompt procedure
Lock the supplied subject, count, action/state, named entities, exact color requirements and literal lettering. Then turn vague intent into a concrete visible arrangement. Add composition, illumination, materials, color relationships and spatial depth that serve that arrangement. The official enhancer emphasizes faithful, objective visual detail and exact text rather than abstract praise. Treat this as disciplined scene expansion, not an invitation to add unrelated content.

## Construct a paragraph in layers
Open with the subject and medium: a studio photograph, a flat illustration, an architectural rendering, a printed poster or another user-selected form. Place the subject with its orientation and action. Define nearby objects and background depth. Choose material-specific appearance and one coherent lighting setup. Add lettering only when requested or visibly necessary. Finish with the composition rather than quality slogans.

For example, “beautiful transparent object” is underspecified. A useful expansion identifies its outline, tint, thickness, highlights and what is visible through it. “A quiet scene” can be expressed through a sparse arrangement, still posture and even soft illumination. “Expensive” can become careful spacing and controlled reflections rather than gold jewelry added without permission.

## Binding and readability
Keep a color/material close to its noun. Count the requested objects. Locate subjects relative to one another and the frame. Use a concrete gaze or contact if the interaction matters. A portrait prompt should specify full-body versus head-and-shoulders before adding clothing details that might be cropped. For a very wide image, design the left/right relationship instead of merely asking for “panoramic.”

## Typography
Quote every exact visible string in straight double quotes. Preserve original script, spelling and punctuation. Name its region and typographic hierarchy. For a poster/menu/interface, specify all user-requested content and which lines are larger or smaller. Do not invent explanatory text to fill space. A clean text-free surface should be described as unmarked rather than given an unwanted placeholder label. English and Chinese rendering are highlighted by the official model card; that does not guarantee error-free Korean or arbitrary tiny lettering.

## Suitable detail level
Turbo accepts developed descriptions, but more words are useful only if they resolve a visual decision. Avoid “8K,” “masterpiece” and redundant quality tags as substitutes for the actual look. Avoid conflicting lens perspectives or simultaneous unrelated illustration styles. A concise brief can expand into a few well-organized sentences; a complex layout needs region-by-region detail. Respect an already precise user prompt and polish it lightly rather than replacing its design direction.

## What is not prompt syntax
Seed, steps, actual width/height, sampling schedule, LoRA strength and output format belong in real controls. Midjourney flags and generic weighted-parenthesis tricks are not portable guaranteed Z-Image controls. A node could parse extra syntax, but that is a distinct implementation and needs explicit support. A negative-prompt blacklist is not a useful default for Turbo's CFG-disabled path.

## Self-review
Check the mandatory inventory, relationships, exact copy, light/material consistency and composition fit. Ask whether every added detail serves the brief. If an image reference was inspected, distinguish observed features from your proposed changes. Deliver one coherent prompt that can be copied into the existing template's positive text field.
